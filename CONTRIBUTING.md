# Contributing

This repository is primarily a software-engineering portfolio project, but contributions and review feedback are welcome.

## Principles
- Keep demo behaviour clearly labelled; do not present simulated integrations as production connections.
- Prefer small, reviewable changes over broad rewrites.
- Keep business rules outside WPF code-behind when adding new features.
- Preserve role checks, auditability and persistence boundaries.
- Add tests when introducing non-trivial domain logic.

## Commit style
Use concise imperative messages such as `Add maintenance risk summary` or `Refactor dashboard metrics into ViewModel`.
